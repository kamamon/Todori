# 頭取 ― 銀行経営シミュレーション

経営破綻した信用組合を引き継いで生まれた地方銀行の「頭取」として経営を担うブラウザゲームです。地元の汐見市で力をつけたら**メガバンク**に格上げして日本全国へ、さらに**テラバンク**として世界へ打って出られます。
タイトル画面で「**会社を経営する**」を選ぶと、お金を借りる側の中小企業の社長になり、業種ごとの商売をしながら帳簿をつけ、決算書を自分の手で作れます。「**法令を守らせる**」を選ぶと、労働基準監督署または消防署の署長として、監督（立入検査）・労働災害や火災の調査・違反の是正を担います。
`index.html` をブラウザで開くだけで動き、サーバーもインストールも不要です。決算書・予算・銀行の勉強に使えるよう、用語の解説と「決算書のどこを見るか」のガイドを手厚くしています。

## 学習サポート

- **用語の解説**：画面の中の点線の下線がある言葉（約170語）を押すと、意味・計算式・決算書のどこを見るか・目安・関連する用語が出ます。メニューの「用語集」でカテゴリー別に探せます。
- **決算書の読み方ガイド**：稟議書や「銀行から見たあなたの会社」で、銀行の審査と同じ順番（売上の伸び → 本業の稼ぐ力 → 財務の安全性 → 返済能力 → キャッシュ・フロー → 売掛金と在庫）に数字を拾い、良好／注意／危険を判定します。「決算書で見る」を押すと表の該当する行が光ります。
- **予算と予実管理**：銀行・会社のどちらでも、4月に予算を立て、毎月の実績との差異（利益への影響の向き）と年間の見通しを確かめられます。
- 学習サポートはメニューから非表示にもできます。

## 会社を経営する（借りる側のモード）

- **2,300の業種**：日本標準産業分類に沿って、農林漁業・鉱業・建設（総合工事・職別工事・設備工事・開発分譲・受注生産の大型設備）・製造（食料品・飲料・繊維・木材・家具・紙・印刷・化学・石油・プラスチック・ゴム・皮革・窯業・鉄鋼・非鉄・金属製品・機械・電子部品・電気・情報通信機械・輸送用機械）・電気ガス（原子力を含む発電）・情報通信（SaaS・AI開発・データセンター・通信事業者・放送・新聞・出版）・運輸（鉄道・航空・海運・トラック・倉庫）・卸売（総合商社・専門商社）・小売・金融・不動産・宿泊・飲食・生活サービス・教育・医療福祉などから選べます。大分類・事業の型・キーワードで検索できます。引き継ぐ会社の状態（好調・普通・不振）と任期も選べます。
- **基幹産業**：原子力（発電所の運転・保守と放射線管理のサービス・定期検査と安全対策と廃炉の工事・燃料とキャスクの製造・使用済燃料の中間貯蔵）、防衛（防衛装備庁や元請の重工からの受注生産：部品・電子機器・艦艇・車両・航空機の整備・弾薬、被服や糧食の量産、関連サービス）、宇宙（小型衛星と部品の受注製造・ロケットの打ち上げ・衛星データ・衛星通信・測位・射場と試験設備）、化学（エチレン・アンモニアなどの基礎化学品、半導体と電池の材料、炭素繊維、バイオ・水素・リサイクル、プラントの建設と定期修理、タンクターミナル）の約100業種。経営の数字（売上・原価・設備投資・資金繰り）として扱い、原子力は13か月ごとの定期検査や規制・裁判での長い停止、防衛は原価計算方式の価格と中間の部分払い、宇宙は5年ほどで入れ替わる衛星への投資、化学は原油（ナフサ）の相場が利益を動かします。
- **9つの事業の型**：店舗で売る（客数×客単価・在庫と廃棄）、飲食（FL比率）、ものづくり（受注加工の稼働率と加工賃・量産ラインと材料スライド・農林水産の収穫期）、工事の請負（見積と受注・工事完成基準・受注残）、仕入れて卸す（粗利と与信・為替の転嫁）、人の力で稼ぐ（人月単価と稼働率）、会員・利用者（解約率・獲得単価・市場の飽和）、施設（稼働率・単価・付帯収入、発電所は利用率・燃料費・基本料金）、運ぶ（積載率・燃料サーチャージ・運賃の市況）。業種ごとに単価・原価率・設備・季節・許認可・関わる法令が違い、開始時に会社の写しで1年ほど試算して、利益率が業界の水準になるよう基準の単価を合わせます（キャリブレーション）。
- **複合業種と新しい事業**：事業はいくつでも組み合わせて始められ、途中から新しい事業を立ち上げたり、撤退したりできます。損益計算書の売上原価は事業の種類ごとの内訳（商品・材料・製造・工事・サービス）になり、セグメント情報で事業ごとの利益が見えます。
- **設備のカタログ**：旋盤・マシニングセンタ・ファイバーレーザー加工機・プレスブレーキ・溶接ロボット・三次元測定機から、製パン・醸造・紡績・抄紙・射出成形・ガラス溶解炉、サーバー・GPU・基地局、客室・倉庫・発電所、トラック・航空機・船まで、能力・価格・耐用年数の違う設備を選んで買えます。
- **成長とアップグレード**：ISOなどの認証、DX（ERP・EC・在庫管理）、省エネ・太陽光、研究開発、海外展開（輸出→海外営業所→海外工場・拠点、為替予約と為替差損益）、M&A（事業の譲受とのれん）、資本政策と株式上場（TOKYO PRO Market・グロース・スタンダード・プライムの形式基準、監査法人の監査、公募増資と売出、上場後の株価・配当と利益準備金・公募増資）、達成した節目の記録。
- **帳簿**：売上・仕入・給与・社会保険料・家賃・経費・入金・支払・借入と返済が、毎月すべて複式簿記で自動記帳されます。仕訳帳（取引ごとの解説つき）・総勘定元帳・試算表・固定資産台帳・売掛金と買掛金の明細を見られます。
- **月次決算**：毎月の損益（速報）と予算の比較、お金の動き、現場の数字、その月の学びのポイント。
- **決算整理（3月末）**：実地棚卸と売上原価（三分法）・工事の確認・減価償却（定額法・月割、間接法と直接法）・貸倒引当金（差額補充法）・未払費用と前払費用（翌期首の再振替）・法人税等（繰越欠損金と均等割）を、手順ごとに解説 → 問題 → 記帳する仕訳の順に進めて決算書を完成させます。在庫の水増しや減価償却の見送りという「誘惑」も選べますが、銀行は回転日数や償却率の変化で気づき、正常な数字に直して評価します。
- **決算書**：損益計算書（売上原価の内訳つき）・貸借対照表・製造原価報告書／完成工事原価報告書・月次推移・キャッシュ・フロー・財務分析・税金の計算。就任前の4期分（先代の経営）も読めます。
- **資金と銀行**：資金繰り表（過去4か月の実績と3か月の予定）、借入金の一覧と繰上返済、銀行・信用金庫・日本政策金融公庫への融資の申込（運転資金／設備資金、手形貸付／証書貸付、信用保証協会の保証、担保）、当座貸越、短期借入金の折り返し、返済条件の変更（リスケ）、緊急の運転資金。銀行は決算書から格付（1〜10）をつけ、金利と貸せる金額が変わります。黒字でも資金が尽きれば経営は終わります（黒字倒産）。
- **設備投資**：出店・改装・冷蔵ケースや厨房機器の更新・機械・トラックの購入を、手元資金か銀行からの借入で行います。大きな施設は完成まで建設仮勘定にためます。自社サービスの開発費はソフトウェア（無形固定資産）に計上して償却します。
- **市況**：景気・物価・賃金に加え、為替・原油・海運の運賃・原材料の相場が動き、大きく動いたときはニュースで知らせます。
- **法令と安全**：36協定・時間外労働の上限・残業代・最低賃金・健康診断・安全衛生の体制・年次有給休暇・労働条件の明示・機械の安全・墜落防止・化学物質・労働保険・防火管理者と消防計画・消防用設備の点検報告・避難訓練・避難通路・自動火災報知設備・危険物・食品衛生（HACCP）・建設業許可・個人情報・電離放射線（被ばくの管理と健康診断）・輸出管理（外為法の該非判定）など、業種と規模に応じた法令の対応を「法令と安全」でこなします。怠ると労働災害・火災の危険が上がり、労働基準監督署・消防署・保健所・経済産業省（輸出管理）などの立入検査で指摘され、期限までに直さないと送検・命令・公表・罰金、銀行の格付の悪化につながります。
- **労災・火災が起きたとき**：救護と現場の保存、労災保険での治療、労働者死傷病報告（労災かくしの危険）、待期期間の休業補償、使用者賠償責任保険、再発防止を、手順ごとの判断で進めます。火災では火災保険・営業の停止・復旧工事。
- **会社の形とグループ経営**：株式会社・合同会社・特例有限会社（組織変更もできる）。子会社の設立（100%・合弁、国内・海外）、事業の分社化（新設分割）、他社の買収（デューデリジェンスと持分の取得、のれん）、子会社株式の売却、日立のような持株会社（ホールディングス）への移行。子会社は表示を切り替えて自分で経営するか、子会社の社長に任せます。親会社は経営指導料・貸付・増資・配当で子会社とお金をやりとりし、決算では連結精算表（内部取引・債権債務・投資と資本の相殺消去、のれんの償却、非支配株主持分、海外子会社の為替換算調整勘定）から連結決算書をつくります。受取配当等の益金不算入（100%子会社は全額、海外子会社は95%）も税金の計算に入ります。
- **グループの再編**：子会社を合併（親会社への吸収合併・兄弟の子会社どうし、効力は期首。抱合せ株式消滅差損益・繰越欠損金の引き継ぎ）、持分の買い増し（追加取得は資本剰余金で処理、株式交換なら現金は要らない）、20〜50%の関連会社（持分法：持分法による投資損益）と、買い増して支配を得たときの段階取得、子会社の下の孫会社（子会社が出資する）、傘下に移す（現物出資か帳簿の価額での売買）、親会社・子会社の社名の変更（定款の変更と登記・看板や名刺の費用）。子会社の資金が足りなくなりそうなときは、親会社が月末に貸し付けます（グループの資金の融通）。グループの構成（組織図）は「くわしく・1行ずつ・子会社だけ」で表示を切り替えられ、会社ごと・孫会社の枝ごとに開いたりたたんだりできます（会社が5社以上になると、はじめは1行ずつ）。
- **カスタムスタート**：会社の形（持株会社で始めると、事業ごとに過去の決算書つきの子会社ができる）、本社の都道府県、資本金・現預金・借入金、本社の土地と建物の有無、景気・為替、創業の年を決めて始められます。就任の時点の帳簿を、増資・減資・配当・借入・繰上返済の仕訳で合わせます。
- **就任の時点のグループ**：始め方の画面で、子会社・孫会社・ひ孫会社・関連会社を、いくつでも、何段でも加えられます。会社ごとに社名・株式を持つ会社・持分（100〜20%。50%以下は持分法の関連会社）・国と所在地・事業（いくつでも）と規模・会社の状態・資本金・現預金・借入金を決めます。国内で事業のある会社は過去4期分の決算書つき、海外の会社と事業のない中間持株会社は就任の時に設立したばかりの会社です。持ち主の帳簿には、下の会社から順に、就任の時点の純資産の持分の額で株式を記帳します（現物出資）。持株会社で始めるときは、事業会社の下にも置けます。会社が多くて自動保存が入りきらないときは知らせ、メニューから使っていないセーブを消せます。
- **方針と人事**：経営方針（顧客第一・品質第一・人的資本経営・コンプライアンス重視など12）と、年度の重点実施事項（賃上げ・DX・原価の低減・健康経営・BCPなど17から3つ）、目標（売上高・経常利益・自己資本比率・労災・残業・従業員満足度など）を決め、決算で振り返ります。福利厚生と手当は、出張手当（日当）・住宅手当・家族手当・資格手当・在宅勤務手当・借上社宅・食事補助（2026年4月から月7,500円まで非課税）・人間ドック・EAP・企業主導型保育所・企業型DC・中退共・カフェテリアプランなど約30の実在の制度から選べ、費用は課税される手当なら給料手当と社会保険料、非課税の制度なら福利厚生費として記帳し、従業員の所得税の扱いも確かめられます。従業員満足度は賃金・賞与・制度・残業・労災で動き、離職・労災・採用の費用・お客さまの満足に効きます。障害者の法定雇用率（2.7%）と納付金・調整金、年間の予定（株主総会・算定基礎届・年末調整など）も。
- **拠点と地図**：47都道府県のタイルの地図で、地価（令和8年の地価調査）・最低賃金（令和8年度）・賃金・災害の起きやすさ・人口を比べ、本社と事業所の移転（事務所移転費用・本店移転の登記）、土地の購入（仲介手数料・登録免許税・不動産取得税）と建物の建設（用途地域・建設仮勘定）、売却、固定資産税、地価の変動ができます。所在地で賃金・家賃・お客さまの数と最低賃金が変わり、地震・台風・豪雨・大雪の災害（特別損失）と火災保険・地震保険・BCPの備えが効きます。世界の地図では、20か国の法人税率・付加価値税・配当の源泉税・賃金・賃料と、守るべき法令（FCPA・GDPR・中国の個人情報保護法・タイの外国人事業法など）を見て、海外展開の進出先や海外子会社の国を選べます。
- **法改正と出来事**：取適法・カスハラ対策の義務化・公益通報者保護法の改正・社会保険の適用拡大（2027年10月から36人以上、2029年10月から21人以上…）・ストレスチェックの義務の拡大などの年表に沿って、会社のやることが増えます。株主総会・決算公告・役員の変更登記・年末調整・電子帳簿保存法・ハラスメント防止・景品表示法・移転価格の文書なども、怠ると法務局・税務署・年金事務所・公正取引委員会・消費者庁・海外の当局の調査で指摘されます。取引先の倒産・大口の注文・値下げの要請・労働組合・内部通報・SNSの炎上・ランサムウェア・税務調査・補助金・原材料の急騰・子会社の不祥事などの出来事には、対応を選んで答えます。
- 任期の終わりに、純資産の成長・稼ぐ力・財務の安全性・銀行の信頼・正しい決算から経営評価（S〜D）が出ます。

## 法令を守らせる（労働基準監督署・消防署のモード）

- **2つの役所**：労働基準監督署（労働基準監督官を率いて工場・建設会社・運送会社・店舗・介護施設などを監督）と、消防署の予防課（店舗・ホテル・雑居ビル・病院などに立入検査）から選べます。管内の法令を守る意識（高い・ふつう・低い）と任期も選べます。
- **限られた人日の配分**：職員の人日を、計画的な監督（立入検査）・案件の調査・措置の判断・集団指導や講習会に配分します。違反は行ってみるまで見えないので、業種と規模・最後の監督からの期間・労災や火災の記録・届出の記録（36協定や点検報告が出ていない）からリスクを見て選びます。使いすぎると職員の残業が増えます。
- **措置の判断**：見つかった違反に、指導票・是正勧告・使用停止等命令・送検（消防は口頭指導・違反指摘・警告・命令・告発、重大な違反は公表）のどれをとるかを決めます。違反の重さ・危険・経過に見合った「標準」の措置とその理由が、選んだあとに解説されます。期日までに直さなければ再監督で次の段階へ。工事などで時間がかかる正当な理由があれば期日の延長も選べます。
- **労災・火災が起きたとき（行政の側）**：死亡災害の災害時監督（初動と原因の調べ方を判断）、休業4日以上の災害調査、労働者からの申告監督、労災かくしの調査、火災原因調査と通報への対応。労災保険の請求では、業務遂行性と業務起因性・通勤の逸脱と中断・過労死と精神障害の認定基準に照らして支給・不支給を決めます（誤って不支給にすると審査請求で取り消されます）。
- **年度の評価**：毎年3月末に、労働災害（火災）と死者の数・計画した監督・局の重点・是正率・措置と判断の適正さ・案件の処理と職員の残業・啓発から、労働局（消防局）の評価（S〜D）が出ます。

## 銀行を経営する（頭取のモード）

- **融資審査（稟議書）**：直近3期の損益計算書・貸借対照表・キャッシュ・フロー計算書と財務分析を読み、調査を指示し、金額・金利（変動／固定）・期間・返済方法・担保・保証を決めて承認か謝絶。決裁欄に頭取印が押されます。
- **粉飾を見抜く**：架空売上、在庫の水増し、費用の資産計上、減価償却不足、簿外債務の5種類。信用調査・代表者面談・実地棚卸・税務申告書の照合・売掛先への残高確認・入出金分析で実態を暴きます。
- **住宅ローン**：返済負担率、担保掛目、収入の偽装や他社借入の隠蔽のチェック。
- **自己査定と引当**：融資先の決算書を毎年検証し、債務者区分（正常先〜破綻先）を決めて貸倒引当金を計上。延滞・返済猶予・期限の利益喪失・サービサーへの売却。
- **金利とALM**：普通預金・定期預金・短期プライムレート・住宅ローン店頭金利を設定（市場連動も可）。日銀の金融政策、国債利回り、金利リスク量。
- **市場運用**：日銀当座預金、所要準備、コール市場、国債の売買と含み損益。
- **金庫・店舗・システム・人員**：金庫の拡張と警備、支店・出張所・ATMの出店、勘定系システムの更改（一括移行／段階移行）、審査システム（粉飾検知・AI審査）、デジタル化、サイバー対策、マネロン対策、採用と給与水準。
- **汐見市の成長**：8つの地区の人口・事業所数・地域活力・地価が、当行の融資や住宅ローン、開発プロジェクト（シンジケートローン）によって変化。街が育つと預金と融資需要が増えます。
- **決算と監督**：複式簿記の総勘定元帳から作る貸借対照表・損益計算書・月次収支・仕訳帳・試算表、自己資本比率（国内基準／国際統一基準）、金融再生法開示債権、監査法人の監査、金融庁検査、行員の不正と臨時監査、格付、株価、配当、株主総会、増資、公的資金。
- **メガバンクへの格上げ**：総資産・地域での預金シェア・自己資本比率・格付・不良債権比率・システムの条件を満たして金融庁に申請（3か月の審査）。認可されると全国の地方銀行2行と経営統合し、首都圏・関西・中部など9地域に店舗網（5段階）を広げられます。地方銀行の買収（株式交換／現金・のれん・隠れた不良債権）、大企業からの大口の融資（M&Aファイナンスを含む）、個人・中小企業向けの小口融資の方針（新規融資の姿勢・金利の上乗せ）、汐見市の小口案件の決裁権限の委譲。
- **テラバンクへの格上げ**：国内の預金シェアを伸ばして海外へ。北米・欧州・中華圏・東南アジア・インド・中東・中南米・オセアニアに、駐在員事務所→支店→現地法人→現地有力銀行の買収→地域統括本部と拠点を広げます。現地の金利、為替の変動と為替ヘッジ、外貨調達コスト、カントリーリスク。
- **格下げのリスク**：上位の業態ほど維持基準が厳しく（自己資本比率 8%・10.5%、格付、不良債権比率、流動性カバレッジ比率、マネロン対策）、2四半期続けて未達だと格下げされ、築いた店舗網を安値で売ることになります。全国規模のシステム障害、不正販売、金融危機での市場損失、各国の通貨危機、地政学リスク、海外当局の制裁金、外貨調達の逼迫、不正なトレーダーなど、規模が大きいほど大きくなる事故も起きます。
- **カスタムスタート**：標準・資本に余裕・不良債権の山・メガバンクから・テラバンクから、のプリセットに加え、業態・資本・預金の規模・承継する貸出の質・店舗数・システム・景気（バブル崩壊前夜も）・金利の水準・粉飾企業の多さ・任期（10年／20年／30年／無期限）・シードを選べます。
- **場面の画像**：タイトル画面、業態（地域銀行・メガバンク・テラバンク）、格下げや経営破綻（取り付け騒ぎ）、金融庁検査、株主総会、本店の金庫に、Canva で生成した場面の画像が出ます。

## GitHub Pages で公開する

1. このリポジトリの **Settings → Pages** を開きます。
2. **Build and deployment** の Source を「Deploy from a branch」、Branch を `main` ／ `/(root)` にして保存します。
3. 1〜2分後に `https://kamamon.github.io/Todori/` で遊べるようになります。

ローカルで遊ぶときは `index.html` をダブルクリックしてブラウザで開いてください（Chrome / Edge / Safari / Firefox の最新版を推奨）。場面の画像は `img/` フォルダにあるので、`index.html` と同じ場所に置いたままにしてください（無くてもゲームは動きます）。

## セーブデータ

- 進行は毎月末と操作のたびに、ブラウザの保存領域（localStorage）へ自動保存されます。メニューから3つのスロットにも保存できます。銀行・会社・役所のモードは別々に保存されます。
- 保存先はブラウザごと・端末ごとです。別の端末で続けるときは、メニューの「ファイルに書き出す」で保存ファイル（JSON）を作り、移した先で「ファイルから読み込む」を使ってください。
- プライベートブラウズなど保存領域が使えない環境では、ページを閉じると進行が失われます。

## 開発

`index.html` は `src/` のファイルを1つにまとめて作っています。直接編集せず、`src/` を直してからビルドしてください（Node.js 18 以上）。

node test/check_capacity.js                  # 製造の業種の設備の能力と注文の釣り合い

node test/fuzz_kaisha.js con 1500 4          # 会社のモードのランダム操作
node test/run_law.js ret,food 5 5            # 会社のモード：法令を守る／守らない経営をボットで比べる
node test/run_group.js 5 2                   # グループ経営：子会社の設立・合弁・分社化・買収・売却・持株会社と連結決算の整合性

## メモ

- 文字は Google Fonts の BIZ UDPゴシック／BIZ UDP明朝を使います。オフラインでは端末の日本語フォントで表示されます。
- スマホ（幅 760px 以下）では、「月末を締めて翌月へ」を画面の下に固定し、ボタン・切り替え・入力欄を指で押しやすい大きさ（高さ 40〜48px、入力欄の文字は拡大されない 16px）にしています。主要な数字は横に滑らせる一列、ダイアログは下から出るシート、ボタンのある表は1行ずつのカード、数字の表は先頭の列を残して横に滑らせ、仕訳帳は借方と貸方を並べた形になります（`src/style.css` の最後の節と、`src/10_ui_core.js` の `markStackTables`）。
- iPhone（iOS 26 以降）の Safari は、スクロールするとページをステータスバーの下まで描いてぼかし（もや）を重ねます。その範囲は無地の帯で覆い、タブとダイアログは帯の下に出しています（`src/style.css` の `--band`）。
- 登場する市・銀行・企業・人物はすべて架空のものです。
